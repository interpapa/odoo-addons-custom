Smart Excel Mass Update & Creation

Bulk update, create, and synchronize your product catalog between Odoo and Microsoft Excel in three simple steps — no technical skills required.

📤 Export to Excel ✏️ Edit on your PC 📥 Sync back to Odoo

🔄 The 3-Step Workflow

Designed to work the same way professionals handle mass data — naturally, without complex field mappings.

📤

1. Export from Odoo

Select products in the Inventory list, click Smart Excel: Export, choose your export mode, and download a formatted Excel file.

→
✏️

2. Edit in Excel

Open in Microsoft Excel or Google Sheets. Update prices, costs, barcodes. Add new rows with blank IDs to create new products. Save the file.

→
📥

3. Sync back to Odoo

Go to Smart Excel: Import, upload your file. Odoo updates existing products by ID and creates new ones automatically.

⚡ Key Features

Everything you need to manage product data at scale — without writing a single line of code or risking data loss.

🛡️

Row-Level Error Isolation

Each row runs inside a database savepoint. If one row fails (e.g. duplicate barcode), only that row is skipped — all others save successfully.

🧹

Smart Data Cleaning

Auto-cleans currency symbols ($, €), European comma decimals (1.500,00), trailing .0 from numeric fields, and extra whitespace.

📦

Dual Export Modes

With IDs for mass updating existing products. Without IDs for exporting data to re-import as brand new products.

📋

Detailed Result Summary

After every import: a green panel shows how many products were updated, created, and a line-by-line log of any skipped rows with reasons.

🌐

Bilingual Interface

Fully translated into English and Spanish. Wizard labels, Excel headers, and log messages switch automatically by Odoo user language.

⚙️

Zero Configuration

Install and go. No setup wizards, no field mapping screens. Fixed intuitive column order — users are productive from day one.

📊

9-Column Template

ID, Internal Reference, Barcode, Name, Sales Price, Cost, Category, Weight (kg), Description — the most critical product fields in one structured file.

🏷️

Category Auto-Lookup

Matches product categories by name during import. Supports short names ("Saleable") and full hierarchy paths ("All / Saleable").

🚀

High Volume Ready

Processes 10,000+ products in seconds. For very large catalogs (50,000+), split into batches of 10,000 rows.

📌 Important Notes & Limits

Be aware of these behaviors before deploying to production environments.

📁 File Format

Only .xlsx files (Excel 2007+) are supported. CSV and legacy .xls formats are not accepted.

📊 Column Order

The module reads by column position, not header name. Always keep columns in the original exported order (A through I).

⚠️ Unique Barcodes

Odoo enforces unique barcodes. A duplicate barcode row is skipped with an error message — all other rows continue processing safely.

⚠️ Category Lookup

If a category name does not exactly match any Odoo category, that field is skipped and the product keeps its existing or default category.
