🎬 How It Works — Real Walkthrough

These are actual screenshots of the module running inside Odoo 17. This is exactly what your team will see.

1

Select products → open the Action menu → click "Smart Excel: Export Products"

In Inventory → Products, check the products you want to update. You can select 1 or 10,000 at once. Then click the Actions button and choose Smart Excel: Export Products from the dropdown. No setup, no configuration, no extra screens.

📈 Business impact: Your warehouse manager or data entry team can do this with zero training. It works exactly like any other Odoo action.
⬇ next step
2

Confirm the export → click "Generate Excel File"

A clean popup appears showing the exact products queued for export (in this example: 3 products — 2 Cabinets and 1 Cable Management Box). One click on Generate Excel File instantly downloads a perfectly formatted .xlsx file with all 9 product fields pre-filled.

⏱ Time saved: What used to take hours of copy-pasting into a spreadsheet now takes 3 seconds.
⬇ next step
3

Open the Excel file → edit freely → save

The downloaded file opens in Microsoft Excel or Google Sheets. Column A contains the Odoo product ID (so the system knows which record to update). Your team edits Sales Price, Cost, Barcode, Category — or any combination. They can also add new rows with a blank ID to create brand new products. When done, they save the file normally.

🔐 No risk: Your team can review ALL changes at once in Excel before importing. One visual audit is worth more than 200 separate saves in Odoo.
⬇ next step
4

Go to Inventory → Operations → "Smart Excel: Import / Sync"

The import lives in the Inventory → Operations menu as a permanent, always-available option. No product selection needed — just click it anytime you have a file ready to upload. This is a dedicated, clean entry point that your team can use independently of whatever products are selected in the list.

🌟 UX design: Import and Export are intentionally separate workflows so there is no confusion. Export = from Odoo to Excel. Import = from Excel to Odoo.
⬇ next step
5

Upload the file → click "Import / Sync to Odoo" → done

Upload your edited .xlsx file and click the green Import / Sync to Odoo button. The system processes every row: products with an ID are updated, rows with a blank ID are created as new products. A detailed result summary appears immediately showing how many products were updated, created, and a log of any skipped rows with the exact reason.

🛡️ Zero data loss: Each row is protected by an independent database savepoint. A bad barcode on row 47 never stops rows 1-46 or 48-200 from saving successfully.
